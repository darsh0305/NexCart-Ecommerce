# Contributing to NexCart

Thanks for your interest in improving NexCart.

## How to contribute

1. Fork the repository.
2. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes and test them.
4. Submit a pull request with a clear summary.

## Coding standards

- Follow the existing Django code style.
- Keep code readable and well-structured.
- Add tests for new functionality when possible.
- Avoid pushing debug code or secrets.

## Reporting bugs

Open an issue with:

- a clear title
- steps to reproduce
- expected behavior
- actual behavior
- screenshots if relevant

## Questions

If you have questions, open a discussion or contact the maintainer.
